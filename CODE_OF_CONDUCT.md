# NyaayWatch Code Of Conduct

NyaayWatch is an open-source civic-data project. Contributions should make the project more accurate, reproducible, and useful to the public.

## Expected Behavior

- Be respectful and direct.
- Assume good intent, but correct mistakes clearly.
- Ground claims in evidence, especially when discussing court data, methodology, or public-facing copy.
- Keep discussion focused on the work: bugs, data quality, reproducibility, accessibility, security, and public usefulness.
- Credit other contributors' work and explain disagreements with technical or methodological reasons.

## Unacceptable Behavior

- Harassment, threats, personal attacks, or discriminatory language.
- Publishing private information, credentials, tokens, or non-public raw data.
- Misrepresenting NyaayWatch data as live, predictive, legally authoritative, or AI-generated legal analysis.
- Deliberately adding unverifiable claims, fake data, or misleading methodology.
- Derailing issue or pull request threads with unrelated arguments.

## Reporting Problems

For conduct issues, open a GitHub issue if the report can be public and non-sensitive. If the report involves security, credentials, private data, or personal information, follow [SECURITY.md](SECURITY.md) instead and do not post details publicly.

Reports should include the relevant issue, pull request, comment, or commit link when available. Maintainers may remove comments, close threads, block users, or reject contributions that violate this code.

## Maintainer Responsibility

Maintainers are responsible for applying this code consistently and in proportion to the issue. The goal is a serious, evidence-first project where contributors can challenge weak ideas without personal attacks or unsafe disclosure.
